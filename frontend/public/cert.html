Cenfri Vault certificate

Install this once per device so the browser trusts the password manager at https://10.10.108.68. Without it you get a "Not secure / connection is not private" warning and the browser won't offer to save your password.

Download the certificate

It is a public certificate. It can only vouch for the Cenfri servers (10.10.108.68, 197.243.26.148, 10.200.200.1), nothing else on the internet.

iPhone / iPad

  1. Open this page in Safari and tap Download the certificate, then Allow.
  2. Open Settings → Profile Downloaded (near the top) → Install → enter your passcode → Install.
  3. Important: Settings → General → About → Certificate Trust Settings → switch on Cenfri Vault Root CA.

Android

  1. Tap Download the certificate.
  2. Settings → Security (or "Security & privacy") → More security settings → Encryption & credentials → Install a certificate → CA certificate → Install anyway → pick the downloaded file.
  3. The menu names differ a little between phone makers — search Settings for "certificate" if you can't find it.

Mac

  1. Download, then double-click the file — it opens in Keychain Access.
  2. Double-click Cenfri Vault Root CA → Trust → "When using this certificate": Always Trust → close and enter your Mac password.
  3. Quit and reopen the browser (Cmd+Q).

Windows

  1. Download, then double-click the file → Install Certificate → Local Machine.
  2. Choose Place all certificates in the following store → Trusted Root Certification Authorities → Finish.
  3. Close and reopen the browser.

Firefox (any computer)

Firefox keeps its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import → tick "Trust this CA to identify websites".
